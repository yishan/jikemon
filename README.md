# 即刻宝可梦图鉴 · Jikémon

把你的即刻（Jike）个人主页变成一张宝可梦风格的收藏卡牌。

灵感来自 [gitfut](https://github.com/Younesfdj/gitfut)（GitHub 资料 → FIFA 球员卡），卡面致敬
[Pokémon TCG](https://asia.pokemon-card.com/hk/card-search/list/?expansionCodes=SVQP)。

## 运行

```bash
node server.js
# 打开 http://localhost:4399，粘贴即刻个人页链接（如 https://web.okjike.com/u/xxxx）
```

零依赖，只需 Node.js ≥ 18。

## 直达链接（改域名即出卡）

站点路由与即刻个人页同构：访问 `/u/<用户ID>` 会自动生成对应卡片。部署到 `jikemon.com`
后，推广话术就是——**把你即刻主页链接里的 `okjike.com` 改成 `jikemon.com`，回车即得
你的专属卡牌**：

```
https://web.okjike.com/u/9db4da53-…   →   https://web.jikemon.com/u/9db4da53-…
```

生成成功后地址栏也会自动同步为 `/u/<id>` 直达链接，方便复制分享。输入框的占位提示
始终展示 `web.okjike.com/u/…` 格式，让用户一眼明白该粘贴什么。

`/api/profile` 有按 IP 的频率限制（每分钟 10 次，内存滑动窗口），超限返回 429。

## 社交分享图（OG Image）

页面会自动注入 Open Graph / Twitter Card meta：

- `/` 与 `/u/<用户ID>` 统一使用静态横版分享图：`/og.png`
- `/og/default.png` 与 `/og/u/<用户ID>.png` 会兼容返回同一张静态图，避免旧缓存或旧链接 404

OG 图为 1200×630 PNG，源文件为 `public/og.svg`，最终社交平台读取 `public/og.png`。
它不在请求时抓取用户资料，避免社交爬虫超时、字体缺失或外链图片失败。

## 数据来源

即刻 Web 端 API 需要登录 token，但移动端分享页 `m.okjike.com/users/<id>` 是公开的 SSR 页面，
`__NEXT_DATA__` 中带有完整的用户资料和最近 10 条动态。服务器端代理抓取（`/api/profile`），
头像经 `/api/img` 代理并附加 CORS 头，保证 canvas 导出 PNG 不被污染。

## 信息转换规则

| 卡片元素 | 即刻数据 | 规则 |
|---|---|---|
| **卡名** | `screenName` | 直接使用昵称 |
| **画面** | 头像大图 | 圆形立绘 + 属性色同心波纹背景 |
| **HP** | 粉丝数、获赞数、即龄 | `40 + 260 × (0.5·粉丝分 + 0.3·获赞分 + 0.2·即龄分)`，对数缩放（10 万粉丝为满分），取整到 10，上限 300 |
| **属性系别** | 圈子投票（发帖数加权 ×2）+ 简介关键词 | 十系：🌿草 🔥火 💧水 ⚡雷 🌀风 👁超 ✊斗 🌙魔 ⚙钢 ★无色 |
| **进化阶段** | 即龄 × 影响力 综合分 | evoScore = 即龄 0.3 + 粉丝 0.6 + 获赞 0.1（对数缩放）；<30 基础，30–58 一阶进化，≥58 二阶进化。影响力主导，蹿升新星靠数据也能进阶，纯熬年头顶不到二阶。**另：6 年+ 且 5000 粉+ 解锁「超进化」流光金徽章** |
| **技能 ×2** | 发帖最多的前两个圈子 | 每个圈子按三层规则判属性（见下），再由圈名哈希从该属性的技能池中选取技能名与效果文案——同一圈子永远同一技能。伤害 = 该圈子获赞×8 + 评论×12 + 转发×15 + 发帖×10 + 粉丝对数加成；能量费用 = 该圈发帖数。圈子不足两个时用行为技能补位（图文占比 ≥40%→「图文并茂」/ 原创率 ≥70%→「原创冲击」/ 否则「转发风暴」） |
| **夸夸强化** | `respectedCount` | 对数曲线 `15·log10(n+1)` 取整到 10：2 次→+10，10 次→+20，100 次→+30，1000 次→+50（封顶），同时写入图鉴文本 |
| **弱点（软肋）** | 发帖最多的圈子 | 本命圈子 = 你最容易上钩的话题，对其「毫无抵抗力」×2；无圈子数据时回退属性克制表 |
| **抵抗力（免疫）** | 几乎不碰的系别 | 圈子里完全没出现的系别 = 你划走不看的领域，对其「免疫」-30 |
| **手速** | 发帖频率 | ≥1.5 条/天 →★★★（日更狂魔）；≥0.5 →★★；否则★（潜水党） |
| **稀有度** | 综合评分（0–100） | 粉丝 30 + 获赞 25 + 即龄 20 + 互动率 15 + 认证 6 + 会员 4。C <30 ≤ U <45 ≤ R <62 ≤ SR <78 ≤ UR |
| **卡框底色** | 稀有度 | C 灰纸 / U 古铜 / R 蓝钢（微光）/ SR 金框（镭射）/ UR 彩虹流光（镭射） |
| **突出特质** | 最强维度 | 取最突出的一项写进图鉴：即龄→稳重、粉丝→号召力、获赞→人气、发帖频率→活力、夸夸→实力；超进化直接封「魅力」 |
| **图鉴描述** | 注册年份 + 属性 + 发帖频率 + 软肋/免疫 + 突出特质 + 粉丝数 | 模板生成风味文本，结尾「其{特质}已吸引 X 只即可梦慕名连接」 |
| **卡片编号** | 注册月日 | `No.MMDD / JIKE` |
| **角标** | 认证 / 会员 | 画面右上角徽章 |

### 圈子 → 属性的三层判定

1. **知名圈子词典**（预先类型匹配，见 `card.js` 的 `TOPIC_TYPE_DICT`）：一个想法不一定对→超、
   AI探索站→超、一起看世界杯→火、手机摄影交流站→水、程序员的日常→雷、深夜聊天室→魔……
2. **关键词分类器**：圈名含「摄影/电影」→水、「旅行/播客」→风、「理财/装备」→钢……
3. **圈名哈希兜底**：陌生圈子用名字哈希稳定映射到一个属性，「随机」但可复现。

没有做全量圈子抓取——即刻没有公开的圈子枚举接口，且圈子随时新增；词典 + 分类器 + 哈希
兜底可以覆盖任意圈子。想扩充词典时直接往 `TOPIC_TYPE_DICT` 加条目即可。

SR / UR 卡带有随鼠标移动的镭射闪光（color-dodge 混合），所有卡片支持 3D 倾斜和 PNG 导出（3 倍分辨率）。

导出用 html-to-image 的 `toSvg` 取矢量快照后自行光栅化——html2canvas 不支持 color-dodge
混合模式会导出发灰；字体通过 Google Fonts 的 `text=` 参数按卡面实际字符请求迷你子集内联，
避免拉取 Noto Sans SC 的 200+ 个 unicode-range 子集文件。

## 项目结构

```
server.js          零依赖 Node 服务器（静态托管 + 数据/图片代理 + OG meta 注入）
public/
  index.html       页面骨架
  og.svg           静态社交分享图源文件
  og.png           静态社交分享图（Open Graph / Twitter Card）
  card.js          转换规则（即刻数据 → 卡片属性）
  app.js           卡片渲染、3D 倾斜、镭射、PNG 导出
  style.css        收藏家桌面 + 宝可梦卡面样式
```
